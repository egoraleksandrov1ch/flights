# Diary Travel

Личный дневник путешествий: перелёты, наземные поездки, страны и города на 3D-глобусе.
Веб-версия приложения Diary Travel для iPhone. Это статический сайт без сервера, все данные хранятся в браузере.

## Возможности

**Diary Fly — перелёты**
- Глобус (MapLibre GL, проекция globe). Линии перелётов идут от оранжевого к синему, будущие рейсы показаны пунктиром.
- Список в стиле Flighty: логотипы авиакомпаний, номер рейса, самолёт, борт, класс, место.
- Фильтр по годам, карточка рейса с историей маршрута.
- Поиск рейсов по маршруту и номеру через AeroDataBox (ключ RapidAPI вводится в профиле).
- База примерно из 7 900 аэропортов, поиск по коду, городу или названию.

**Diary Country — страны и путешествия**
- Посещённые страны закрашиваются на глобусе. Острова и территории (Канары, Мадейра, Азоры, Балеары и другие) показываются отдельно и не входят в счёт стран.
- Слои «Страны» и «Города»: пины городов, где вы были.
- Путешествия: страны, даты, рейсы за эти даты подтягиваются сами.
- Наземные поездки (автобус, поезд, машина, паром) через несколько городов, без линий на карте.
- Ручная отметка стран и городов.
- «Где я живу»: дом за указанный период не попадает в топы городов и стран.

**Статистика**
- Перелёты: километры, круги вокруг Земли и путь до Луны, годы, сезонность, дни недели, время вылета, самолёты с картинками, авиакомпании, аэропорты, маршруты, классы и тепловая карта мест в салоне.
- Страны и путешествия: части света, где вы бывали чаще всего, новые страны по годам, города, путешествия, наземные поездки.

**Языки**
- Интерфейс на 9 языках: английский, русский, украинский, польский, немецкий, испанский, французский, итальянский, португальский. Язык берётся из настроек браузера, его можно сменить в профиле. Названия Diary Fly, Diary Country и Diary Travel не переводятся.
- Названия стран, даты и числа подставляются на выбранном языке автоматически.

**Поделиться**
- Посадочный талон и карта стран, в формате «Билет» или «Сторис».

**Данные**
- Экспорт и импорт в JSON. Формат общий с приложением для iPhone: перелёты, путешествия, поездки, страны, города, места жительства, ключ API.
- Добавляя импорт к текущим данным, повторяющиеся перелёты (тот же маршрут и дата) не дублируются, а дополняются.

## Файлы

| Файл / папка | Что это |
|---|---|
| `index.html` | весь сайт: разметка, стили, код |
| `i18n.js` | переводы интерфейса (ключ — русская строка из `index.html`) |
| `airports.json` | база аэропортов |
| `airlines.json` | авиакомпании: название, ICAO, позывной |
| `countries.json` | контуры стран, островов и территорий |
| `seatmap.png` | схема салона для тепловой карты |
| `flags.json` | флаги стран (SVG) — вместо эмодзи, которых нет в Windows |
| `planes/` | картинки самолётов (`plane_737ng.png` и т. д.) |
| `lib/` | MapLibre GL, topojson, контуры суши для карточек |
| `icon.svg`, `favicon-32.png` | значок во вкладке браузера |
| `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `manifest.webmanifest` | иконка для экрана «Домой» |

## Размещение на GitHub Pages
1. Загрузите все файлы и папки в корень репозитория.
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

**На iPhone как приложение:** откройте сайт в Safari, нажмите «Поделиться», затем «На экран „Домой“».

Локально: запустите `python3 -m http.server` в папке проекта и откройте http://localhost:8000.
Двойной клик по `index.html` не сработает: браузер не даст загрузить JSON-файлы.

## Важно про данные
Данные живут только в этом браузере на этом устройстве (`localStorage`). Если очистить данные сайта, они удалятся, поэтому периодически делайте **Экспорт** в профиле.
Файл экспорта содержит ваш ключ AeroDataBox, не отправляйте его посторонним.

## Статистика посещений
На сайте стоит счётчик [GoatCounter](https://www.goatcounter.com): без cookies, без личных данных, только число визитов, страны и устройства. Ваши перелёты и страны он не видит — они остаются в браузере.
