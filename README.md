# Мои перелёты

Статический сайт: 3D-глобус с вашими перелётами. Все данные хранятся в `localStorage` браузера.

## Возможности
- Глобус (globe.gl / three.js), перелёты рисуются анимированными дугами
- База ~7 900 аэропортов с IATA-кодами, поиск по коду, городу или названию
- Статистика: рейсы, километры, аэропорты, страны
- Клик по перелёту в списке или по дуге — камера летит к маршруту
- Экспорт / импорт в JSON (резервная копия и перенос между устройствами)

## Размещение на GitHub Pages
1. Создайте репозиторий и загрузите в корень все файлы: `index.html`, `airports.json`, папки `img/` и `lib/`.
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет по адресу `https://<логин>.github.io/<репозиторий>/`.

Локально: `python3 -m http.server` в папке проекта и откройте http://localhost:8000
(двойной клик по index.html не сработает — браузер не даст загрузить airports.json).

## Важно про localStorage
Данные живут только в этом браузере на этом устройстве. Очистка данных сайта их удалит — периодически делайте **Экспорт**.

Источник базы аэропортов: [mwgg/Airports](https://github.com/mwgg/Airports) (MIT).
